## 长战役：架构评估与扩充方向（2026-08-01）

[exec/24](exec/24-长战役-架构评估与扩充方向.md)。**方向定稿，不是执行规格。**

结论：现在的架构靠三条假设立着，长战役破掉两条，但**真正的架构断裂只有一条**
——`keeper_state` 里有一半是模型现编的自由文本键（实测：`科比特态度`、
`包裹状态` 与 `当前场景节点`、`玩家位置` 混在同一个 dict 里）。
**散文不可裁剪**，所以分层注入永远有一块裁不掉的残留，而它随对局时长线性增长。

方向不是新架构，是把 exec/14 已定的 `view(subject)` **从可见性贯彻到世界模型**：
世界 = 一组有 id 的实体 + 挂在其上的状态，上下文是一次查询而不是全量倾倒。
两阶段回合制、两段式掷骰、L1/L3、规则权威全部不动。

无论做不做战役都该做的两件：**`pending` 落库**（现在后端一重启就整局死锁，
是真 bug 不是战役专属）、**世界状态自由键收口**（要求挂在已知实体 id 上）。
